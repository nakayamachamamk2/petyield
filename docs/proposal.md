# PetYield

_Raise NFT pets that passively earn tokens through daily mini-games_

## Summary

PetYield lets players mint an NFT pet that earns yield over time, boosted by completing short daily mini-games and quests. Pets level up, unlock new earning multipliers, and can be bred or traded, creating a casual play-to-earn loop with low time commitment. All pet stats, earnings, and breeding logic run through Solana smart contracts for transparency.

## Target users

Casual mobile-style gamers wanting low-effort crypto earning

## Problem

Hardcore play-to-earn games demand too much time investment, alienating casual players who want simple daily engagement.

## Solution

A low-friction idle/casual game where a few minutes of daily play meaningfully boosts token earnings from an owned NFT pet.

## MVP features

- Mint NFT pet with base yield rate stored on-chain
- Daily mini-game (tap/timing challenge) that boosts yield multiplier for 24h
- Claim accrued token rewards via on-chain program
- Pet leveling system unlocking cosmetic traits and higher base yield
- Breeding mechanic combining two pets into a new NFT with inherited traits

## Chains

Solana

## Tech

Anchor, React Native, Metaplex, Solana Pay, Switchboard (for randomness), Node.js

## Category

Gaming

## Why now

Solana's cheap microtransactions make daily claim/boost interactions economically viable even for small reward amounts.
